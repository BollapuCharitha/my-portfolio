# Bollapu Charitha — Portfolio

A responsive, animated personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.

For the best local development experience, open the folder in VS Code and use the Live Server extension.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `charitha-portfolio`).
2. Upload all files and folders from this package. Keep `index.html` at the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. After GitHub Pages publishes the site, copy the URL and add it to your LinkedIn profile and resume.

## Before publishing
- Check the phone number, email, LinkedIn and GitHub links.
- Review the project descriptions to ensure they accurately reflect your contribution.
- The College Fest card links to the live page URL included in the portfolio.
- Add direct repository links for each project if you want recruiters to open the source code directly.
- Keep `assets/Charitha_Resume.pdf` in place so the Download Resume link works.

## Files
- `index.html` — portfolio content
- `style.css` — responsive styling and animations
- `script.js` — mobile navigation, typing effect, scroll reveal and progress bar
- `assets/Charitha_Resume.pdf` — resume download
